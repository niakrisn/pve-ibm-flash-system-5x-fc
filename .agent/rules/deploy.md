## 1. Deployment Safety
- Для деплоя используй ТОЛЬКО установку через пакет, который ты можешь собрать в локальном докере. Никогда не копируй код или накалдывай патчи на удаленном хосте. Единственный способ добсавить код на сервер это пакет.
- НИКОГДА не использовать `rsync --delete` на системных директориях PVE.
- Перед деплоем — синхронизировать тесты через `./scripts/sync_tests.sh`.
