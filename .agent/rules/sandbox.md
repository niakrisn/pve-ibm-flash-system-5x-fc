## 1. Test Execution (Fail-Fast Mode)
При выполнении интеграционных тестов (`prove`, `*.t` файлы):
- При ЛЮБОМ провале теста — НЕМЕДЛЕННО СТОП.
- НЕ пытаться автоматически исправить ситуацию.
- Собрать evidence (multipath, lsblk, qm config, логи).
- Предоставить отчет и ЖДАТЬ одобрения пользователя.
- Тесты запускать ТОЛЬКО последовательно (один процесс).

## 1. Test Environment
- Тестовое окружение доступно по адресу 10.4.0.122, подключиться можешь пользоателем root используя ключ ~/.ssh/id_ed25519
- Запрещается работать с блочными устройствами, которые сейчас используются файловыми системами
- Твоя рабочая папка - /usr/share/perl5/PVE/Storage/Custom/
- Интеграционные тесты нужно запускать на этом окружении, проверки синтаксиса и т.п. тоже нужно проверять на этом окружении
- Доступ к СХД только через код плагина, напрямую (wget, curl и прочее) нельзя
- СХД работает в боевом режиме, поэтому тебе можно работать только с пулом pool-pvc-01. Все есть в конфиге хранилок PVE. Используй хранилище fs-01, только его.
- Так же доступно локальное СХД local-lvm для тестов в которых нужно переносить диски и VM между СХД.
